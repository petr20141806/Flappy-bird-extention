# Flappy Bird Mini для Google Chrome

Самостоятельная реализация небольшой аркады с управлением одним кликом. Игровая логика, физика, столкновения, подсчёт очков и звуковые сигналы написаны отдельно для этого расширения. Это не копия чужого исходного проекта.

## Возможности

- Запуск из значка расширения Chrome.
- Классическая аркадная механика с управлением кликом мыши.
- **Режим бота:** включите кнопку «БОТ: ВКЛ», и автопилот будет сам управлять птицей. Повторное нажатие возвращает ручное управление.
- Счёт и сохранение рекорда через `chrome.storage.local`.
- Пауза и продолжение игры.
- Звуковые эффекты с возможностью отключения.
- **Настройки:** звук, три уровня сложности и сброс рекорда. Настройки сохраняются между запусками.
- Экран готовности и проигрыша, повторный запуск.
- Резервная встроенная графика, если внешние спрайты недоступны.
- Никаких удалённых скриптов: игровой код хранится внутри расширения.

## Установка в Chrome

1. Распакуйте ZIP-архив в отдельную папку.
2. Откройте `chrome://extensions`.
3. Включите **Режим разработчика**.
4. Нажмите **Загрузить распакованное расширение**.
5. Выберите папку `flappy-bird-extension`.
6. Нажмите на значок расширения в панели Chrome и играйте.

## Графические ресурсы

Используются спрайты из репозитория [samuelcust/flappy-bird-assets](https://github.com/samuelcust/flappy-bird-assets): фон, земля, зелёная труба, три кадра жёлтой птицы и экран Game Over. Из-за ограничений среды сборки эти изображения загружаются по прямым адресам GitHub Raw при открытии игры. Для оригинальных спрайтов необходимо подключение к интернету. Если загрузка не удалась, включается локальная резервная отрисовка.

Лицензионное уведомление для набора ресурсов находится в `ASSET-LICENSE.txt`.

## Звук и приватность

Короткие звуковые эффекты генерируются локально через Web Audio API. Расширение не отправляет данные пользователя на серверы и не запрашивает доступ к сайтам. Разрешение `storage` используется только для сохранения рекорда и выбранных настроек (звук и сложность).
